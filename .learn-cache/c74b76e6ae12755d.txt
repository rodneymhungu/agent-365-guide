Microsoft Agent 365
Microsoft Agent 365 is a Microsoft 365 service that provides a centralized control plane for AI agents. It enables organizations to discover, manage, govern, and secure agents across their environments. Agent 365 works with agents built on Microsoft platforms and with agents built or acquired from third‑party sources; and integrates with Microsoft 365 administration, identity, security, and compliance capabilities.
Available plans
Microsoft Agent 365 is available as a stand-alone subscription for use with eligible Microsoft 365 subscriptions and is also included with Microsoft 365 E7.
For detailed plan information on subscriptions that enable users for Microsoft Agent 365, see the Microsoft 365 Enterprise plan comparison, Microsoft 365 Business plan comparison, and Microsoft 365 Education plan comparison.
