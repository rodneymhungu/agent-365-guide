## Headline

What changed this week in the Agent 365 field guide

## Body

Updated this week: the Agent 365 field guide for security and compliance engineers.

Eight things moved on Microsoft Learn, and the guide moved with them:

• **Conditional Access for agents** has a stated **licence requirement**: Microsoft 365 E7, or an Agent 365 licence with at least Entra ID P1 or Microsoft 365 E3. Generally available; Microsoft says enforcement of the Agent 365 licence is coming. agent-365-guide/#s2-1

• **Registry sync** has a **setup page per platform**, and the **permissions differ**. Amazon Bedrock and Oracle need only read access, with delete rights optional. Google Vertex AI requires the delete permission. A delete in Agent 365 reaches the source platform, so check what each connection can delete before you save it. agent-365-guide/#s5-4

• The **Agent 365 SDK** no longer handles **observability**. Its observability packages are deprecated in favour of the separate **Microsoft OpenTelemetry Distro**; identity, tooling and notifications stay in the SDK. agent-365-guide/#s5-4

• The **Microsoft 365 admin centre** setting that controls which agents users can install is now **Agent and plugin access**, and it also governs **plugins**: tools, MCP servers, connectors and skills. agent-365-guide/#s6-4

• **Defender for Endpoint runtime protection** for local agents can be **deployed from the Defender portal** as well as Intune, which reaches devices under security settings management. Public preview, and devices need the Beta Channel for platform and engine updates. agent-365-guide/#s7-4

• **Deleting an agent** is a **soft delete** for every agent type, with thirty days to restore it. agent-365-guide/#s6-3

• The **Risks column** in the **agent registry** counts high, medium and low severity signals. A zero means no active signal at any severity. agent-365-guide/#s5-3

• Both administrators and **AI administrators** can **activate templates** and **delete instances** of agents with their own identity. Frontier preview. agent-365-guide/#s6-8

Every claim in this guide links to Learn. GA/Preview status badges follow Microsoft's release notes, checked every Monday.

See what changed and what you can deploy today: https://rodneymhungu.github.io/agent-365-guide/#s10
