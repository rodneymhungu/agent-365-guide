## Headline

What changed this week in the Agent 365 field guide

## Body

The Agent 365 field guide for security and compliance engineers: which product enforces each control, what it needs, and what works today.

Three things moved on Microsoft Learn, and the guide moved with them:

• **Defender for Endpoint local agent discovery** now finds local AI agents and their MCP servers on onboarded Windows and macOS devices, with nothing to deploy. Public preview. agent-365-guide/#s5-5

• **Intune native policy for agent runtime protection**: an endpoint security Antivirus profile now covers agent-native event inspection, so only network inspection still needs a PowerShell platform script. Runtime protection is in preview. agent-365-guide/#s7-4

• **Agent 365 registry sync adds Snowflake Cortex** to the platforms whose agents can be pulled into the inventory. GA. agent-365-guide/#s5-4

• Also new to the guide: a table that starts from your scenario ("a developer installs Claude Code on a laptop") and lands on the control, the product that enforces it, and its status today (agent-365-guide/#s4-1); and the licensing chapter on its own page (agent-365-guide/licensing.html).

Every claim in the guide links to Learn. GA/Preview status badges follow Microsoft's release notes, checked every Monday.
