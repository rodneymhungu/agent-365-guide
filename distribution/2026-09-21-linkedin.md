**Updated this week: the Agent 365 field guide for security and compliance engineers.**

Three things moved on Microsoft Learn, and the guide moved with them:

• Defender for Endpoint local agent discovery is now GA. macOS stays in preview.
• Intune has a native policy for agent runtime protection. The PowerShell script is only for network inspection now.
• Snowflake Cortex agents can be synced into the Agent 365 registry.

Also new: a table that starts from your scenario ("a developer installs Claude Code on a laptop") and lands on the control, the product that enforces it, and whether you can deploy it today.
