    Field guide 01 · Microsoft Agent 365 · Changes

    What changed in the Agent 365 field guide, and when

    Agent 365 moves weekly, and so does the Learn documentation behind it. Every Monday each Learn page this guide cites is read again, and when one has moved the guide moves with it. This page is the record: one entry per change, newest first, with the section it touched and the Learn page it came from. Entries about the guide itself are marked Guide.

    40 changes logged 18 October 2026 last reviewed 4 September 2026 first published Every Monday Learn pages re-read

    A status badge in the guide changes only when Microsoft's release notes say so; a Learn page dropping "(Preview)" from its title is not enough. To follow changes as they land, subscribe to the feed or watch the repository.

    10

    October 2026

    18 October 2026

    • 5.5 The Defender for Endpoint AI agent support matrix is now the source for both Defender columns of the lookup table: Claude Desktop in Code mode and the GitHub Copilot and Claude Code extensions for Visual Studio Code gain agent hooks, ChatGPT Desktop and Ollama Desktop gain network inspection, Antigravity Desktop and Microsoft Scout are discovered, and Codex CLI is named by the runtime protection overview but absent from the matrix. Sixty tools on Windows, fifty-one on macOS. AI agent support matrix page cited.
    • 7.4 Runtime protection's supported agents come from the support matrix: six agents with hooks, four under network inspection. AI agent support matrix page cited.
    • 5.4 Observability on Connected platforms now covers five platforms, Salesforce Agentforce and Databricks Genie joining Bedrock, Vertex AI and Anthropic, and each connection has a Collect agent observability data switch, on by default, whose queries the provider bills. The two Learn pages disagree about older connections. Connected platforms and Third-party agent observability pages cited.
    • 5.4 Two onboarding walkthroughs for agents you build: a single agent with the Agent 365 CLI, and bulk onboarding from one CSV with PowerShell. Both pages cited.
    • 5.6 Observability data for Foundry and Copilot Studio agents includes prompts and responses, stored in the tenant's default geography whatever the Azure region, and each platform has a control to stop sending it. Data handling for Azure agents page cited.
    • 2.1 Agent risk-based Conditional Access needs Entra ID P2 or Microsoft 365 E5 beside Agent 365, the one policy in 7.1 that E3 does not cover. Secure autonomous agents with Conditional Access page cited.

    12 October 2026

    • 7.1 Policies in the Users assignment exclude agent user accounts whether they target all users, selected users, groups, roles or external users; scope agent users with the Agents assignment instead. Conditional Access for agents page cited.
    • 5.6 Observability collection starting only once a trial or licence is active now applies to third-party agents and to tenants in ten listed countries, including Austria, Denmark and Spain. Data handling, data residency, and compliance page cited.
    • 6.6 Access packages for agents grant OAuth API permissions, delegated and application, for Microsoft Graph and applications. Governing agent identities page cited.
    • 5.5 Defender for Endpoint lists a local agent only after it observes activity, so discovery is not a full software inventory. Local AI agent discovery page cited.
    • 2.1 Dropped the claim that Agent 365 licence enforcement for Conditional Access is coming: the autonomous agents policy page now lists the licence plans without that notice. Secure autonomous agents with Conditional Access page cited.

    11 October 2026

    • 6.3 Management rules number five: Apply a template joins the four bulk actions, each rule takes conditions that select the agent instances it runs on, and the template rule is a one-off run limited to registry agents with an identity. Microsoft's September What's new post calls custom rules a public preview and lists more conditions than Learn does. Agent settings page and the post cited.
    • 5.3 AI mode, a natural-language search of the registry for ownerless, inactive or review-worthy agents, announced as a public preview in Microsoft's September What's new post. No Learn page yet, so it carries the early preview label.
    • 5.4 Azure API Management integration: agents, tools, models and MCP servers onboarded there appear in Agent 365 without manual registration, rolling out from 30 September per Microsoft's September What's new post. No Learn page yet, so it carries the early preview label.
    • Guide Chapter buttons under the 6.7 and 7.5 videos jump to their chapters. The review date, prices and key dates sit in the page text for crawlers and link previews. Each part of the page script runs on its own, so one missing element no longer stops the rest.

    6 October 2026

    • 5.4 Connected platforms is the current name for what Microsoft announced as Registry sync in April 2026, and several Learn pages still use the old name; observability differs by platform: the hub lists it for Amazon Bedrock, Google Vertex AI and Anthropic, with the other four coming soon, and third-party agent observability is a Frontier preview whose page also lists Salesforce Agentforce. Connected platforms and Third-party agent observability pages cited.
    • 6.8 Admins can create an agent instance on behalf of a manager: a Global Administrator or AI Administrator starts it from the agent's details in the registry, a wizard checks licences first, and the manager owns the instance in Entra and Teams. Create agentic user instances page cited.
    • Guide Writing and structure pass: 5.5 and 7.2 open on their verdict, 2.1 and 7.4 split into one claim per sentence, the hero names all five enforcing products, 4.1 lists all seven synced platforms, and cross-references use bare section numbers.
    • 6.4 The Allowed agent types setting is now Agent and plugin access and also governs plugins, meaning tools, MCP servers, connectors and skills; Microsoft-built ones stay visible when disabled but cannot be installed. Agent settings page cited.
    • 5.4 Each registry sync platform now has its own setup page, and the permission scope varies: Amazon Bedrock and Oracle need only read access, with delete rights optional, while Google Vertex AI requires the delete permission. A delete in Agent 365 reaches the source platform. All seven setup pages cited.

    5 October 2026

    • 5.4 The Agent 365 SDK no longer bundles observability: Microsoft deprecated the SDK's observability packages in favour of the separate Microsoft OpenTelemetry Distro, keeping identity, tooling and notifications in the SDK. Agent 365 SDK overview page cited.
    • 5.4 Dropped the claim that registry sync scheduling is promised: the connected platforms page no longer states a scheduled-sync roadmap, only that synchronisation is manual. Connected platforms page cited.
    • 2.1 Conditional Access for agents now states its licensing as Microsoft 365 E7, or an Agent 365 licence paired with at least Entra ID P1 or Microsoft 365 E3; the companion autonomous agents policy page confirms Agent 365 licence enforcement is still coming. Conditional Access for agents page cited.
    09

    September 2026

    28 September 2026

    • 7.4 Runtime protection can now be deployed from the Microsoft Defender portal as well as Intune, reaching devices under Defender for Endpoint security settings management; public preview also requires the Beta Channel for platform and engine updates. Runtime protection setup page cited.
    • 6.3 Deleting an agent is now a soft delete with a thirty-day recovery window and a restore option, for any agent type, not an irreversible Agent Builder-only removal. Agent actions page cited.
    • 5.3 The Risks column and Risk details pane now cover high, medium and low severity signals, not high alone; a zero means no active signal at any severity. Agent registry page cited.
    • 6.8 AI administrators, not only administrators, can activate templates and delete agent instances. Manage agent instances page cited.

    27 September 2026

    • Guide Structure pass: 5.4 and 6.1 open on their answer, 6.2 custom templates and 7.3 real-time protection coverage are tables, 5.5 names each tool once, 7.4 says which admin-centre page blocks what.
    • 5.5 5.5 gains a lookup table of which surface detects which local AI tool and which can block it, joined from the Shadow AI, Local agents, Defender discovery and runtime protection pages.

    21 September 2026

    • 5.5 Defender for Endpoint local agent discovery stays in preview. Learn's page dropped its preview label, but the Defender for Endpoint release notes and the portal still say preview, and there is no GA entry.
    • 7.4 Intune now has a native Antivirus policy for agent-native event inspection; network inspection still needs a PowerShell platform script. Runtime protection setup page cited.
    • 5.4 Snowflake Cortex joins registry sync's supported platforms. Connected platforms page cited.
    • 4.1 Chapter 4 gains a scenario-to-control table: start from what you need to stop, land on the control, the enforcing product and its status.
    • 2 Chapter 2 is also published on its own page, licensing.html, so the licensing question can be found on its own.

    14 September 2026

    • 5.5 Local agents page: the detected developer-tool list has grown substantially and blocking now covers Gemini CLI, VS Code extensions and OpenClaw's Node.js siblings. Learn page cited.

    9 September 2026

    • 2.1 Licensing prerequisites corrected after Microsoft product marketing feedback: Entra ID P1 comes with every plan that qualifies for Agent 365. Licensing FAQ cited.
